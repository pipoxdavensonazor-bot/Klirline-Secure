# Deploy Netlify - KlirSecure
1. Netlify > Add new site > Deploy manually > glissez le CONTENU de ce dossier (index.html, app.js, netlify.toml, netlify/).
2. Ou : drag & drop le ZIP fourni (il contient ces fichiers a la racine).
3. URL fournie par Netlify. HTTPS actif par defaut.
Limites version statique : stockage local (localStorage), IA desactivee, audit URL via proxy integre (GET passif uniquement).
